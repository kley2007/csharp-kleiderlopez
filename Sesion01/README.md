## Comparación de instrucciones en Python, JavaScript y C#

| Instrucción | Python | JavaScript | C# |
|---|---|---|---|
| Mostrar texto | `print("Hola")` | `console.log("Hola");` | `Console.WriteLine("Hola");` |
| Leer datos | `input("Nombre: ")` | `prompt("Nombre:")` | `Console.ReadLine();` |
| Crear variable | `nombre = "Nehi"` | `let nombre = "Nehi";` | `string nombre = "Nehi";` |
| Condicional | `if edad >= 18:` | `if (edad >= 18) { }` | `if (edad >= 18) { }` |
| Ciclo | `for i in range(5):` | `for (let i = 0; i < 5; i++) { }` | `for (int i = 0; i < 5; i++) { }` |
| Crear función | `def saludar():` | `function saludar() { }` | `static void Saludar() { }` |

### Conclusión

Aunque los tres lenguajes permiten realizar tareas similares, su sintaxis cambia. Python utiliza una estructura más sencilla, mientras que JavaScript y C# utilizan llaves en estructuras como los condicionales y ciclos. C# también requiere declarar tipos de datos en muchas variables.
